# 관리자 화면 (`/admin`)

[[신고]]를 사람이 검토하고 처리하는 화면입니다.
- 파일: `public/admin.html`, 서버는 `api/admin.js`
- 2026-11-06에 V-01 조치로 생겼습니다.

## 들어가기
- 관리자 비밀번호를 입력합니다.
  - 요청 헤더 `x-admin-password`의 SHA-256 값을 Vercel 환경 변수 `ADMIN_PASSWORD`와 비교합니다.
- **틀리면:** 1초 늦게 401과 "관리자 비밀번호가 맞지 않아요."를 돌려줍니다.
- **환경 변수가 없으면:** 503을 돌려줍니다.
- 비밀번호는 페이지 메모리에만 있어서 창을 닫으면 잊힙니다.
- 검색 노출 금지(`noindex, nofollow`)와 캐시 금지(`no-store`)가 걸려 있습니다.
- 비밀번호는 사용자가 `admin-password.ps1`을 직접 실행해 설정합니다. 비밀번호를 묻는 대화형 스크립트입니다.

## 할 수 있는 것
| 동작 | 결과 |
|---|---|
| 목록 보기 | 처리 대기(`open`) 또는 전체(`all`), 최대 200건. 신고자·대상 닉네임, 방, 메시지 포함 |
| `hide_message` / `unhide_message` | 메시지를 "신고로 가려진 메시지예요."로 바꾸거나 되돌립니다. 되돌리면 방 제목·목록 미리보기도 복원됩니다. |
| `hide_room` / `unhide_room` | 다른 편들어 주는 사람 목록에서 방을 빼거나 되돌립니다. |
| `resolve` / `reopen` | `cb_reports.reviewed_at` 처리 완료를 표시하거나 지웁니다. |

## 확인 상태
- 로그인 화면은 2026-11-06에 확인했습니다.
- **로그인 뒤 화면은 아직 실제 주소에서 확인하지 못했습니다.** 비밀번호는 사용자만 압니다.
