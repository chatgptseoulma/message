# 메신저 화면 (`/`)

로그인한 뒤 쓰는 본 화면입니다. 파일은 `public/index.html`입니다. 왼쪽 메뉴(300px)와 오른쪽 화면으로 나뉩니다.

## 왼쪽 메뉴
- **계정 상자:** 이모지, 닉네임, 역할, **계정 바꾸기**(→ [[시작-화면]])
- **＋ 새로 쏟아내기**
- **내 하소연 방**, **받은 하소연** 목록
  - 각각 최대 100개입니다.
  - 안 읽은 방은 숫자 배지와 주황 점으로 표시됩니다.
  - 8초마다 새로 고칩니다 → [[폴링]]
- **숨긴 방 · 그만둔 방 (N):** 접었다 펼 수 있습니다 → [[숨기기와-그만두기]]
- **하단 메뉴:**
  - 🔔 새 메시지 알림 켜기 → [[알림]]
  - 🙋 편들어 주기 설정
  - ⚙ 내 정보 · 차단 목록
- **상담 전화 안내:** → [[위기-안내]]
- 탭 제목에 안 읽은 방 수가 붙습니다. 예: "(2) 퇴근길 빡침 우체통"

## 오른쪽 화면 (주소 해시)
| 해시 | 화면 |
|---|---|
| `#/` | 처음 화면: "오늘 뭐가 그렇게 열받았어요?" |
| `#/new` | 새로 쏟아내기 → [[위로받는-사람]] |
| `#/r/<방 id>` | [[하소연-방]] |
| `#/give` | 편들어 주기 설정 → [[편들어-주는-사람]] |
| `#/me` | 내 정보: 닉네임, 이모티콘, 차단 목록, [[열쇠]], 계정 빼기·지우기 |

## 입력
- Enter로 보내고, Shift+Enter로 줄을 바꿉니다. 한글 입력 중에는 보내지 않습니다.
- 빈 메시지를 보내면 "뭐라도 적어요. 한 줄이면 돼요."가 뜹니다.
- 보내기 버튼을 누르면 먼저 흐린 말풍선이 뜹니다. 실패하면 "실패 · 다시"를 눌러 재전송합니다.
- **🙂 이모지 판:** 48개가 있고, 커서 자리에 넣습니다.
- 쓰다 만 글은 저장됩니다 → [[쓰다-만-글]]

## 좁은 화면 (폭 760px 이하)
- 한 화면씩 보입니다. 각 화면 머리의 **☰**를 누르면 왼쪽 메뉴가 서랍처럼 열립니다.
- 바깥을 누르거나, Esc를 누르거나, 다른 화면으로 가면 닫힙니다.
- 입력칸은 최소 64px로 커집니다.
- 높이가 560px 이하인 창에서는 왼쪽 메뉴 전체가 스크롤됩니다 (D-02 수정).

## 내 정보의 계정 정리
- **이 기기에서 이 계정 빼기:** 이 브라우저에서만 지웁니다. 서버에는 남습니다.
- **내 기록 모두 지우기:** 되돌릴 수 없습니다.
  - 닉네임, 편들어 주기 등록, 내 하소연 방, 내 메시지가 서버에서 연쇄 삭제됩니다.
  - 내 방에 남이 쓴 답글도 함께 지워집니다.

## 화면 표시 방식
- 모든 글을 `textContent`로만 그립니다. 그래서 XSS 위험이 없습니다.
- 다크 모드는 OS 설정을 따릅니다.
