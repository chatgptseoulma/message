# 데이터베이스 (Supabase Postgres)

- **프로젝트:** Supabase 프로젝트 ref `fwpxfnbjwkzuglyrmraz`. 설문 앱 **survey-vercel과 함께 씁니다.**
- **표 이름:** 모두 `cb_` 접두사를 붙입니다.
- **보안:** RLS를 켜 두고 정책은 두지 않았습니다. anon·authenticated 권한도 회수했습니다. 그래서 **서버([[API]])만 읽고 쓸 수 있습니다.**
- **`updated_at`:** 앱 코드가 갱신합니다. 트리거는 없습니다.

| 표 | 내용 |
|---|---|
| `cb_users` | id, token_hash([[열쇠]] 해시), nickname 1~20자, emoji, created_at |
| `cb_comforters` | user_id, intro ≤100, active → [[편들어-주는-사람]] |
| `cb_threads` | [[하소연-방]]: seeker_id, comforter_id(비어 있으면 방송형), title, closed, moderated, last_id/last_body/last_author(목록용 사본), updated_at |
| `cb_messages` | thread_id, author_id, body 1~2000자, deleted_at(회수), moderated(가림) |
| `cb_reads` | (방, 사용자)별 마지막으로 읽은 id → [[읽음-표시]] |
| `cb_room_prefs` | (방, 사용자)별 hidden_at, stopped → [[숨기기와-그만두기]] |
| `cb_blocks` | blocker_id, blocked_id → [[차단]] |
| `cb_reports` | 신고자, 대상, 방, 메시지, 사유, 상세 ≤300, reviewed_at → [[신고]] |
| `cb_reactions` | (메시지, 사용자, 이모지) → [[공감-반응]] |
| `cb_signup_log` | 가입 IP의 HMAC 해시 + 시각. 2일 보관 → [[악용-방지-제한]] |

## 연쇄 삭제
- 사용자를 지우면 그 사람의 방, 메시지, 반응이 함께 지워집니다.
- 신고 기록도 대상 메시지와 함께 지워집니다. 이 문제는 [[알려진-이슈와-과제]]의 V-04에 있습니다.

## 마이그레이션 (적용 순서)
1. `20261105000000_responses.sql`: **설문 앱의 파일. 지우면 안 됩니다.**
2. `20261105100000_comfort_letters.sql`: 첫 표들
3. `20261105200000_broadcast_rooms.sql`: [[방송형-방]], `cb_reads`
4. `20261106000000_safety_and_prefs.sql`: 이모지, 회수, 신고, 차단, 방 설정
5. `20261106100000_reactions.sql`: 공감 반응
6. `20261106200000_abuse_limits_admin.sql`: 가입 기록, `reviewed_at`

적용 방법은 [[배포와-DB-변경]]에 있습니다.
