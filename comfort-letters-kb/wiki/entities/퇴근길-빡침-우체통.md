# 퇴근길 빡침 우체통 (comfort-letters)

익명 하소연 메신저 웹앱입니다. 저장소 폴더 이름은 `comfort-letters`입니다.

| 항목 | 값 |
|---|---|
| 주소 | https://comfort-letters-five.vercel.app |
| 화면 | `/start` [[시작-화면]], `/` [[메신저-화면]], `/admin` [[관리자-화면]] |
| 서버 | Vercel 서버 함수, 서울 리전 `icn1` → [[API]] |
| 저장 | Supabase Postgres. 설문 앱(survey-vercel)과 같은 프로젝트를 씁니다. → [[데이터베이스]] |
| 빌드 | 없음. 정적 HTML과 Node 20 ESM |
| 소스 | `C:\2026CC\comfort-letters\` |

## 특징
- **가입:** 회원가입과 이메일이 없습니다. 닉네임과 [[열쇠]]만 씁니다.
- **역할:** [[위로받는-사람]]과 [[편들어-주는-사람]] 두 가지입니다.
- **방:** 쏟아낼 때마다 [[하소연-방]]이 생기고, 모두에게 갑니다 ([[방송형-방]]).
- **안내 문구:** 시작 화면에 "실명이나 회사 이름은 빼요. 뒷감당은 소중하니까."가 있습니다.
- **답장 태도:** "답할 땐 훈계 금지, 해결책도 금지." 자세한 내용은 [[편들어-주는-사람]]에 있습니다.
