# 자료 요약: 실제 주소 확인 기록 (2026-11-06)

- **원본:** `raw/2026-11-06_실제주소_확인기록.md`
- **방법:** 배포된 앱을 앱 안 브라우저로 실행했습니다. **계정은 만들지 않았습니다.**

## 확인한 것
- `/` → 열쇠가 없어 `/start`로 이동했습니다.
- `/start`: 문구, 닉네임 예시 4개, 이모지 41칸, 열쇠 입력, 상담 안내 → [[시작-화면]]
- `/admin`: 로그인 화면과 "신고는 자동으로 가려지지 않아요." 안내 → [[관리자-화면]]
- `GET /api/comforters`: 200, **16명** → [[편들어-주는-사람]]

## 확인하지 못한 것
- **로그인 뒤 메신저 화면:** 실제 운영 사이트라 계정을 만들지 않았습니다. 소스 코드와 테스트 결과서로 보완했습니다.
- **관리자 로그인 뒤 화면:** 비밀번호가 없습니다.
