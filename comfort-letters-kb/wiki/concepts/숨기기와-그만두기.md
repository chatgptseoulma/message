# 숨기기와 그만두기

내 목록에서 [[하소연-방]]을 정리하는 두 가지 방법입니다. 사람마다 방별로 `cb_room_prefs`에 저장합니다.

| | 숨기기 | 편들어 주기 그만 |
|---|---|---|
| 누가 | 모두 (방 주인 포함) | 방 주인이 아닌 [[편들어-주는-사람]] |
| 메뉴 | ⋯ → 🙈 이 방 숨기기 | ⋯ → ✋ 이 방 편들어 주기 그만 (확인창 있음) |
| 목록 | "숨긴 방 · 그만둔 방"으로 이동 | 같음. 목록에 [그만둠] 표시 |
| 새 메시지가 오면 | **다시 원래 목록에 나타남** | 계속 숨겨져 있음. 안 읽음 점도 안 뜸 |
| 글쓰기 | 가능 | **불가** (입력칸 대신 안내. 서버도 400) |
| 되돌리기 | 👁 목록에 다시 보이기 | 🙋 다시 편들기 |

- 방 주인이 "그만"을 요청하면 400입니다. 방 주인은 대신 방을 닫습니다.
- 그만둔 방 안내 문구: "편들어 주기를 그만둔 방이에요. 오른쪽 위 ⋯ 에서 '다시 편들기'를 누르면 다시 쓸 수 있어요."
- 숨긴 방이 다시 나타나는 조건: 숨긴 시각보다 방의 `updated_at`이 늦으면 다시 나타납니다.
