# 위기 안내

글에서 위기 신호가 보이면 상담 전화를 먼저 안내하는 기능입니다.

- **감지하는 말 (정규식):** 죽고 싶 / 자살 / 극단적 / 사라지고 싶 / 살기 싫 / 목숨 / 끝내고 싶 / 자해
  - 띄어쓰기가 있어도 잡습니다.
- **감지 위치:** 쏟아내기 입력칸과 방 입력칸
  - 글을 쓰는 동안 바로 확인합니다.
  - 이모지 판으로 넣은 글도 확인합니다.
- **안내 문구:** "많이 힘드시군요. 지금 바로 이야기를 들어 줄 사람이 있어요. 자살예방 상담전화 109 (24시간, 무료)로 전화해 주세요."
  - 109는 누르면 전화가 걸리는 `tel:` 링크입니다.
- **전송은 막지 않습니다.**
- **늘 보이는 안내:**
  - [[시작-화면]] 하단
  - [[메신저-화면]] 왼쪽 메뉴 하단
  - 번호: 자살예방 상담전화 109 · 정신건강 위기상담 1577-0199 (24시간)
- **처리 위치:** 브라우저에서만 검사합니다. 서버는 이 단어를 검사하거나 기록하지 않습니다.
