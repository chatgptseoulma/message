# 악용 방지 제한

누구나 무료로 계정을 만들 수 있어서 생기는 악용(스팸, 신고 악용)을 막는 제한값입니다.

| 항목 | 제한 | 초과 시 | 도입 |
|---|---|---|---|
| 가입 | 같은 IP에서 24시간에 20개 | 429 | V-02, 2026-11-06 |
| 방 만들기 | 계정당 24시간에 10개 | 429 "하소연 방은 하루 10개까지…" | V-02, 2026-11-06 |
| 메시지 | 계정당 1분 20개, 하루 500개 | 429 | 첫 배포 |
| 신고 자동 가림 | **없음.** 관리자가 검토합니다. → [[관리자-화면]] | – | V-01, 2026-11-06 |
| 같은 대상 중복 신고 | 1번만 | 409 | 2026-11-06 |

## 입력 길이·형식
| 항목 | 규칙 |
|---|---|
| 닉네임 | 1~20자. 눈에 안 보이는 문자(폭 없는 공백, 방향 바꾸기 문자)는 지웁니다. 이모지를 잇는 ZWJ는 남깁니다. |
| 하소연·메시지 | 1~2000자 |
| 한 줄 소개 | 100자 |
| 신고 상세 | 300자 |
| 프로필 이모지 | 정해진 40개만 |
| 공감 반응 | 6종만 |

## IP 기록
- IP 원문은 저장하지 않습니다.
- 서버 비밀값으로 만든 HMAC-SHA256 해시만 `cb_signup_log`에 저장합니다.
- 2일이 지난 기록은 가입할 때마다 지웁니다.
- IP 헤더가 없으면 제한하지 않습니다.

## 남은 약점
- 메시지 제한 확인이 원자적이지 않습니다. 동시에 요청하면 몇 개 더 넘길 수 있습니다.
- 닉네임 변경, 공감, 차단 같은 동작에는 횟수 제한이 없습니다.
- 테스트할 때 주의: 테스트 가입도 같은 네트워크의 하루 20개에 포함됩니다.
