# 질문: 앱 안에서 무엇을 검색·조회할 수 있나?

**질문일:** 2026-11-06

**답:** 앱에는 **검색창이 없습니다.** 내 계정에 보이는 것을 화면에서 직접 찾습니다.

| 어디서 | 볼 수 있는 것 |
|---|---|
| 내 하소연 방 | 내가 쏟아낸 방 (최대 100). 제목, 마지막 메시지 미리보기, 시각, 안 읽음, [닫힘] |
| 받은 하소연 | 편들어 주는 사람일 때, 계정을 만든 뒤에 생긴 남의 방 (최대 100) → [[방-볼-권한]] |
| 숨긴 방 · 그만둔 방 | → [[숨기기와-그만두기]] |
| 새로 쏟아내기 | 지금 하소연 받는 사람 수 |
| 방 안 | 대화 (최대 1000), 편들어 준 사람 수, [[공감-반응]] 수, [[읽음-표시\|읽은 사람]] |
| 내 정보 | 닉네임, 이모지, 차단 목록, [[열쇠]] |
| `/admin` | 신고 목록 (최대 200) → [[관리자-화면]] |

## 찾는 법
- **방:** 왼쪽 목록을 훑습니다. 새 메시지가 온 방이 위로 올라옵니다.
- **대화 속 문장:** 방을 연 뒤 브라우저 찾기(Ctrl+F)를 씁니다.

## 볼 수 없는 것
- 다른 사람의 방 목록과 통계
- 계정을 만들기 전의 방
- 차단 관계인 사람의 글
- 전체 데이터 조회는 DB에서만 됩니다. → [[하소연-많이-한-사람-찾기]]

## 개선 아이디어 (제안)
- 왼쪽 목록 위에 방 검색창을 둡니다. 제목과 미리보기로 거릅니다.
- 화면만 바꾸면 되고 서버 변경은 필요 없습니다.
