# 질문: 누가 하소연을 제일 많이 했나?

**질문일:** 2026-11-06

## 답
- **앱 화면으로는 알 수 없습니다.**
  - 사용자별 통계 기능이 없습니다.
  - 새 계정은 가입한 뒤에 생긴 방만 봅니다. → [[방-볼-권한]]
- 실제 데이터는 서버만 읽을 수 있습니다. → [[데이터베이스]]
  - **Supabase 대시보드 SQL Editor**에서 운영자가 직접 조회해야 합니다.

## 쿼리 (읽기 전용)
```sql
-- 쏟아낸 방 수와 방 안에서 하소연한 메시지 수, 많은 순 상위 10명
select u.nickname,
       count(distinct t.id) as 쏟아낸_방,
       count(m.id)          as 하소연_메시지
from cb_users u
join cb_threads t  on t.seeker_id = u.id and t.comforter_id is null
left join cb_messages m on m.thread_id = t.id and m.author_id = u.id and m.deleted_at is null
group by u.id, u.nickname
order by 쏟아낸_방 desc, 하소연_메시지 desc
limit 10;
```

## 해석할 때 주의
- **기준:** "하소연"은 **쏟아낸 방 수**로 셉니다. 방 안에서 더 쓴 메시지 수도 함께 봅니다.
- **옛 1:1 방:** 집계에서 빠집니다. 넣으려면 `and t.comforter_id is null`을 지웁니다.
- **탈퇴한 사람:** 연쇄 삭제로 기록이 이미 없습니다.
- **같은 사람의 여러 계정:** 각각 따로 셉니다.
- **개인정보:** 익명 서비스이므로 결과 닉네임은 운영 확인용으로만 씁니다. **이 위키에는 결과를 기록하지 않습니다.**
