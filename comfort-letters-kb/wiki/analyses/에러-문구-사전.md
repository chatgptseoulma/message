# 에러 문구 사전

| 문구 | 상태 | 뜻 / 해결 |
|---|---|---|
| 뭐라도 적어요. 한 줄이면 돼요. | (화면) | 빈 글을 보냈습니다. |
| ○○을(를) 적어 주세요. | 400 | 필수 입력이 비었습니다. 예: "메시지을(를) 적어 주세요." 조사가 어색한 것은 공통 문구 때문입니다. |
| ○○ 형식이 올바르지 않아요. | 400 | 글 자리에 글이 아닌 값이 왔습니다. 예: "하소연 형식이 올바르지 않아요." |
| 고를 수 있는 이모티콘이 아니에요. | 400 | 정해진 40개 밖의 이모지입니다. |
| 반응할 수 없는 메시지예요. | 400 | 회수됐거나, 가려졌거나, 차단한 사람의 메시지입니다. → [[공감-반응]] |
| 방을 찾을 수 없어요. | 404 | 방이 없거나 볼 권한이 없습니다. → [[방-볼-권한]] |
| 이 방을 더 볼 수 없어요. | (화면) | 열어 둔 방의 권한이 도중에 없어졌습니다. |
| 하소연 방은 하루 10개까지… | 429 | 방 만들기 한도입니다. → [[악용-방지-제한]] |
| (429) | 429 | 메시지 1분 20개 / 하루 500개, 또는 가입 IP당 하루 20개를 넘었습니다. |
| (409) | 409 | 같은 대상을 이미 신고했습니다. → [[신고]] |
| 관리자 비밀번호가 맞지 않아요. | 401 | [[관리자-화면]] 비밀번호가 틀렸습니다. |
| 다시 들어와 주세요. | 401 | 열쇠가 거절됐습니다. 시작 화면으로 이동합니다. → [[열쇠]] |
| 문제가 생겼어요. 다시 시도해 주세요. | 500 등 | 서버 오류입니다. 계속되면 Vercel 로그를 확인하세요. |
| 실패 · 다시 | (화면) | 메시지 전송이 실패했습니다. 누르면 다시 보냅니다. 마우스를 올리면 원인이 보입니다. |
