# commute-break/

A deployable copy of the root `퇴근길쉼표.html` (Vercel, static).

**Before you answer a question or start work, read [docs/commute-break.md](../docs/commute-break.md) first.**

- `퇴근길쉼표.html` and `commute-break/index.html` have the same body, so a change to one should go into the other too.
- `index.html` here is the reference for adding a document wrapper (`<!doctype>`/`<head>`) to a root HTML fragment before deploying it.
- How to deploy: see the root `CLAUDE.md`.
