# 로컬 영상 생성 (내 PC로 만들기)

ComfyUI 같은 도구로 오픈 모델([[미니맥스-H3]], [[Wan]] 등)을 내 그래픽카드에서 돌리는 방법입니다.
- **장점:** 크레딧이 들지 않습니다.
- **단점:** 하드웨어와 시간이 듭니다.

## 하드웨어 (방 안 의견)
- **VRAM:** 16GB면 무난합니다. 5070 Ti 16GB와 3060 12GB도 돌아갑니다 (L9-17, L843-846).
  - 가속 LoRA를 쓰면 8GB(3060 Ti)도 됩니다 (L1347-1348).
- **엔비디아 vs 맥:** 영상 생성은 엔비디아(CUDA)가 맥보다 빠릅니다. 이미지는 비슷합니다 (L819-850).
- **사양을 넘기면:** 스텝 수 등을 PC 성능 이상으로 올리면 GPU 대신 CPU로 넘어가 몇 시간씩 걸립니다 (L127-138).
- **LLM과 비교:** 로컬 LLM이 영상 생성보다 VRAM을 더 씁니다 (L5-7).

## 생성 시간 예시
| 사양·설정 | 결과 | 줄 |
|---|---|---|
| 5070 Ti 16GB, 0.9MP | 8초 영상 14~20분 | L9-17 |
| 3060 12GB, 데노 워크플로 | 10초 영상 약 700초 | L395, L846 |
| 0.2MP + 업스케일 | 8초 영상 약 5분, 15초도 5분 | L576, L623, L704 |
| 뉴디스 설정 (4스텝 + 8스텝 LoRA, 레이턴트 업스케일, RTX 업스케일, 프레임 보간) | 15초 영상 309초 | L699-740 |
| 뜰의 측정 | 이미지 1장 25초, 4초 영상 98초 | L5334-5336 |

## 속도 높이는 요령
- **데노 워크플로 (저해상도 생성 후 업스케일):** 20스텝 대부분을 약 0.15MP로 돌리고 마지막 3스텝만 고해상도로 돌립니다 (Mr.HAN, L395-402).
  - **r2v 전용**이라 i2v에서는 결과가 나쁩니다 (L407).
  - sol 노드 에러가 나면 노드를 지우고 새 버전으로 다시 연결합니다 (L420).
- **빠른 동작이나 작은 얼굴:** 레이턴트 업스케일을 끄고 1MP로 돌립니다. 시간은 2배쯤 걸립니다 (뉴디스, L699-740).
- **어텐션:** Sol, Sage, Kitchen 어텐션을 씁니다. 검증이 많이 된 **Sage가 충돌이 적습니다**. 라데온은 따로 확인해야 합니다 (L377-391).
- **얼굴 뭉개짐:** ComfyUI에 **FaceDetailer** 노드를 추가합니다 (두따, L2477).
- **설치:** 노드 설치와 워크플로 생성은 코덱스나 클로드에게 맡기면 편합니다 (L392-418).

## PC가 약하면: GPU 빌리기
- **RunPod**(https://www.runpod.io/)에서 시간당 요금으로 GPU를 빌려 ComfyUI나 Wan2GP를 돌립니다 (로킹, L3134-3166).
- wan2gp.com은 다른 사이트이니 주의하세요 (L3139-3143).

## 회원 파이프라인
- **두따 (RAM 64GB, RTX 5080):** [[YuE2]]로 작곡 → Krea2로 캐릭터 시트 → 로컬 미니맥스 H3(ref2v)로 영상 → 프리미어로 편집 → AE로 자막 (L4049-4050)
- **Mr.HAN:** [[드리미나]] 스토리 스튜디오로 대본과 에셋 → [[뮤즈-AI|뮤즈]]로 미니맥스용 프롬프트 → RunningHub API로 영상 (L6193-6194)
