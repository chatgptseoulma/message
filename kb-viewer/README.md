# KB 뷰어

`docs/kb`(카카오톡 대화로 만든 LLM Wiki)를 브라우저에서 보는 로컬 앱입니다.
- 파이썬 표준 라이브러리만 쓰므로 설치할 것이 없습니다.
- 파일을 고치지 않고 읽기만 합니다.

## 실행
- **더블클릭:** `KB뷰어-실행.bat`을 실행하면 브라우저가 http://127.0.0.1:8765 를 엽니다. 창을 닫으면 꺼집니다.
- **명령줄:**
  ```bash
  python C:\2026CC\kb-viewer\server.py
  ```
- **옵션:** `--kb <볼트 경로>` (기본값 `../docs/kb`), `--port 8765`
- **Claude 앱 미리보기:** `.claude/launch.json`의 `kb-viewer`

## 다른 사람과 공유하기 (공유본)
서버나 파이썬 없이 **더블클릭만으로 열리는 HTML 파일 하나**를 만듭니다. 인터넷이 없어도 열립니다.

1. `공유본-만들기.bat`을 더블클릭합니다. 명령줄에서는 `python build.py`입니다.
2. `dist/` 폴더에 파일 두 개가 생깁니다.

| 파일 | 크기 | 들어 있는 것 | 언제 |
|---|---|---|---|
| `KB뷰어.html` | 약 420KB | 위키 페이지, 그래프, 통계. **카톡 원문은 없습니다.** 줄 번호는 글자로만 보입니다. | 다른 사람에게 보낼 때 (권장) |
| `KB뷰어_원문포함.html` | 약 970KB | 위의 것에 더해 카톡 원문 전체. 줄 번호를 누르면 원문으로 이동하고, 원문도 검색됩니다. | 대화 참여자처럼 원문을 봐도 되는 사람에게만 |

3. 파일을 메일, 메신저, USB로 보냅니다. 받는 사람은 더블클릭하면 브라우저(Chrome, Edge 등)에서 열립니다.

- 위키를 고친 뒤에는 공유본을 **다시 만들어야** 반영됩니다. 공유본은 만든 날짜 기준이고, 화면 위에 "공유본 2026-11-06"처럼 표시됩니다.
- **원문 포함본:** 단톡방 사람들의 닉네임과 메시지가 그대로 들어 있습니다.
- **원문이 없는 파일:** 위키 페이지에도 이름이 나옵니다. 예를 들어 아침인사방 페이지에는 참여자 이름이 있습니다. 받는 사람을 가려서 보내세요.

## 화면
| 화면 | 주소 | 내용 |
|---|---|---|
| 문서 | `#/page/<이름>` | 왼쪽: 파일별·분류별 목록 (이름 거르기). 가운데: 속성, 본문. 오른쪽: 백링크, 나가는 링크 |
| 원문 | `#/raw/<폴더>?l=5145-5149` | 카톡 원문을 줄 번호와 함께 보여 줍니다. 지정한 줄을 노란색으로 표시하고 그 줄로 이동합니다. 줄 이동, 원문 안 찾기, 날짜 줄 강조 |
| 채팅 | `#/chat` | 위키에 문장으로 묻고 Claude의 답을 받습니다. 아래 "채팅" 참고 |
| 검색 | `#/search?q=…&raw=1` | 위키 점수순 검색. 원문(카톡 대화)까지 찾으면 줄로 바로 이동합니다. `/` 키로 검색창에 갑니다 |
| 그래프 | `#/graph` | 위키 링크 그래프. 폴더별 색, 끌어서 이동, 휠로 확대, 클릭하면 문서가 열립니다 |
| 통계 | `#/stats` | 방별 메시지·사람·사진·링크 수, 날짜별·시간대별 막대, 많이 말한 사람. 날짜 막대를 누르면 그날 원문으로 갑니다 |

## 💬 채팅 (위키에 묻기)
"실사 영상은 어떤 모델이 나아?"처럼 문장으로 물으면, 위키를 근거로 Claude가 답합니다. **로컬 서버로 실행했을 때만** 됩니다. 공유본 HTML에서는 안내만 나옵니다.

- **처음 한 번 로그인:** PowerShell에서 `& "$env:USERPROFILE\.local\bin\claude.exe"`를 실행하고 `/login`을 입력한 뒤, 브라우저에서 로그인을 마칩니다.
- **답이 만들어지는 과정:**
  1. 질문에서 낱말을 뽑습니다. 조사와 흔한 말은 뺍니다.
  2. 관련 위키 페이지 6쪽과 카톡 원문 줄(방마다 최대 15줄)을 고릅니다.
  3. 고른 자료를 근거로 넘겨 `claude -p`가 답합니다.
- **답 아래 "근거":** 참고한 페이지 링크가 붙습니다. 답 속 `AI영상방 L5145` 같은 표시를 누르면 원문 줄로 갑니다.
- **시간과 비용:** 답 하나에 보통 10~40초 걸립니다. Claude 사용량이 들고, 한 번에 한 질문씩만 처리합니다.
- **안전:**
  - Claude 쪽 도구는 모두 끕니다(`--tools ""`). 자료 속 문장이 명령처럼 보여도 Claude가 파일을 읽거나 무엇을 실행할 수 없습니다.
  - 이 PC의 브라우저에서 보낸 요청만 받습니다. Host 확인과 전용 헤더로 다른 사이트의 요청을 막습니다.
- **다른 경로:** Claude CLI가 다른 곳에 있으면 `python server.py --claude <claude.exe 경로>`로 지정합니다.
- **대화 기록:** 대화는 이 브라우저 탭에만 저장됩니다(sessionStorage). "대화 지우기"로 비울 수 있습니다.

## 원문 줄 연결
- 위키 본문과 "근거" 속성에 있는 `L5145`, `L5145-5149` 같은 줄 번호는 모두 링크입니다. 누르면 그 폴더 `raw/`의 txt 원문 해당 줄로 갑니다.

## 구조
- `server.py`: API와 마크다운 변환
  - `/api/tree`, `/api/page`, `/api/raw`, `/api/search`, `/api/graph`, `/api/stats`
  - `127.0.0.1`에서만 열립니다.
  - 원문은 볼트 안 각 폴더의 `raw/`에 있는 파일만 읽습니다.
- `build.py`: 공유본을 만듭니다. `server.py`의 함수로 모든 페이지·그래프·통계(·원문)를 미리 만들어 `index.html` 안에 `window.KB_DATA`로 넣습니다.
- `static/index.html`: 화면 전체. 외부 라이브러리를 쓰지 않습니다.
  - `KB_DATA`가 있으면 서버 대신 파일 안의 데이터를 씁니다. 검색도 브라우저 안에서 합니다.
  - 다크 모드는 OS 설정을 따릅니다.
  - 폭이 760px 이하면 ☰ 버튼으로 목록을 엽니다.

## 참고
- 통계의 "많이 말한 사람"은 닉네임 뒤의 `/지역`을 빼고 보여 줍니다. 위키 규칙(`docs/kb/CLAUDE.md`)을 따른 것입니다.
- 위키를 고치거나 새 대화를 넣으면 새로 고침만 하면 됩니다. 파일 변경 시각을 보고 다시 읽습니다.
