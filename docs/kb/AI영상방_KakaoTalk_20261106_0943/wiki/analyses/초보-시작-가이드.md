# 초보 시작 가이드 (방 안 답변 종합)

AI 영상을 처음 시작하는 사람에게 방에서 실제로 해 준 조언을 순서대로 묶었습니다.

## 1단계: LLM과 친해지기
- **GPT 무료판**부터 써 봅니다. 이미지를 그릴 수 있고 사용량이 넉넉해서 초보에게 권합니다 (L3563-3602, L3808-3813). → [[GPT-코덱스]]
- **코딩은 몰라도 됩니다.** "그냥 대화하면 된다"는 답이었습니다 (L3668-3673).

## 2단계: 무료로 연습하기
- [[Flow]]의 매일 무료 크레딧으로 짧은 영상을 만들어 봅니다 (L3230-3244).
- 편집은 [[편집-툴|캡컷]]으로 시작합니다 (L3601).

## 3단계: 모델과 예산 정하기
- [[영상-모델-비교]]를 보고 모델을 먼저 정한 뒤 플랫폼을 고릅니다.
- **예: 월 10만 원**이면 [[시댄스]] 기준 약 2분 30초~3분입니다 (대학 과제 상담, 11월, L5442-5523).
- 저화질로 여러 모델을 시험해 본 뒤 고릅니다 → [[크레딧-비용-절약]]

## 하지 말 것
- **고가 유료 강의 (300만 원 등):** 대부분 말렸고, 방에서는 문의도 금지입니다. 대신 다음을 권했습니다 (L2503-2743).
  - 구독료로 직접 해 보기
  - 방장 영상
  - 지자체 무료 교육
- **외주로 비싸게 사기:** 광고 영상을 외주로 50만 원에 산 사례에는 비싸다는 반응이 많았습니다 (L3557-3676).
