description: LLM Wiki 점검 (lint) — 링크·고아·모순·낡은 정보
---
`docs/kb/CLAUDE.md`의 점검 절차를 실행하세요.

1. `python -I _tools/kb_lint.py .`를 실행합니다.
   - **오류**(깨진 링크, 이름 겹침, frontmatter, 표 안 별칭)는 모두 고칩니다.
   - **경고**(고아, 목차에서만 연결, 줄 번호 없음)는 관련 페이지에서 링크를 걸거나 근거를 보충합니다.
2. 직접 읽어 확인합니다.
   - 페이지끼리 모순되는 내용
   - 날짜가 오래된 가격·한도·버전
   - 여러 페이지에 나오는데 자기 페이지가 없는 도구나 개념
3. 고친 내용과 남은 제안을 해당 `<방>-기록`과 볼트 `log.md`에 `## [오늘] lint | 요약`으로 적습니다.
4. 다시 `kb_lint.py`를 돌려 오류 0건을 확인하고 결과를 보고합니다.
