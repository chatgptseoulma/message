---
description: LLM Wiki에 질문하기 (query) — 답을 위키에 남길 수 있음
argument-hint: <질문>
---
`docs/kb/CLAUDE.md`의 묻기 절차로 다음 질문에 답하세요: $ARGUMENTS

1. `index.md`와 관련 폴더의 `<방>-목차`를 읽습니다.
2. `python -I _tools/kb_search.py . "<핵심 낱말>"`로 페이지를 찾습니다.
   - 위키에 없으면 `--raw`를 붙여 원문을 찾습니다.
3. 찾은 페이지를 읽습니다. 숫자나 인용은 `raw/` 원문 줄로 확인합니다.
4. 답할 때 근거 페이지를 `[[페이지]]`로, 원문을 `L123`으로 밝힙니다.
   - 위키에 없는 내용은 "위키에 없음"이라고 말합니다.
5. 다시 쓸 만한 답이면 사용자에게 묻고 `analyses/`에 페이지로 남깁니다.
   - 그 경우 목차와 기록에 `## [오늘] query | 질문`을 추가합니다.
   - 개인정보나 "넣지 않는 것"에 해당하는 결과는 남기지 않습니다.
