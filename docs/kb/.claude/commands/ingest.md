`docs/kb/CLAUDE.md`의 스키마를 따라 다음 파일을 위키에 넣으세요: $ARGUMENTS

1. 파일을 찾지 못하면 `C:\2026CC\카카오톡\`에서 가장 최근 txt를 후보로 보여 주고 확인을 받습니다.
2. 첫 줄의 방 이름과 저장 시각으로 폴더 이름 `<방>_KakaoTalk_<YYYYMMDD>_<HHMM>`을 정합니다.
   - 방 이름이 없거나 길면 짧은 이름을 제안하고 사용자에게 물어봅니다.
   - 폴더를 만든 뒤 txt를 `raw/`로 복사합니다. 원본은 옮기지 않습니다.
3. `python -I _tools/kakao_stats.py <raw의 txt>`를 실행해 기간, 메시지 수, 날짜 경계, 나눠 읽을 구간을 얻습니다.
4. 구간별로 읽습니다. 2천 줄이 넘으면 구간마다 하위 에이전트를 써서 병렬로 읽습니다.
   - 각 구간에서 화제, 도구, 노하우, 질문과 답, 링크, 규칙을 **줄 번호와 함께** 뽑습니다.
   - "넣지 않는 것" 목록은 빼고 뽑습니다.
5. 핵심 인용 몇 줄은 원문에서 직접 대조합니다.
6. 페이지를 만들거나 고칩니다. 틀은 `_templates/`에 있습니다.
   - `sources/src-<방>-대화`
   - 방 entity
   - 도구·개념·분석 페이지
   - 이미 있는 이름이면 그 페이지에 단락을 추가합니다.
7. 다음 페이지를 고칩니다.
   - `<방>-개요`, `<방>-목차`, `<방>-기록` (`## [오늘] ingest | 파일명`)
   - 볼트 `index.md`의 표
   - `log.md`
8. `python -I _tools/kb_lint.py .`를 실행해 오류가 0건이 될 때까지 고칩니다.
9. 무엇을 넣고 뺐는지, 몇 쪽을 만들었는지, 검증하지 못한 것을 짧게 보고합니다.
