# 작업 규칙 (저장소 전체, 항상 적용)

## 새 파일 저장 위치
- 새로 만드는 파일은 사용자가 따로 위치를 지시하지 않는 한 **이 폴더(C:\2026CC) 바로 아래에 두지 말고**, 작업마다 하위 폴더를 새로 만들어 그 안에 저장한다.
- 하위 폴더 이름은 작업 내용을 알 수 있는 한글 또는 영문 이름으로 짓는다 (예: `survey`, `교육자료`).
- 기존 작업의 파일을 고치거나 추가할 때는 그 작업의 기존 하위 폴더를 그대로 쓴다.
- 이 폴더의 기존 파일들(html, 스크린샷 등)은 사용자 파일이므로 옮기거나 지우지 않는다.

## 저장소 개요
This folder is not a single codebase. It is a collection of small, independent Korean-language web apps. There is no git repository and no root package.json. Regression tests live in `tests/`.

Each app folder has its own `CLAUDE.md` with its rules. **Before you answer a question or start work, read the matching reference doc first.** It records the full results of a complete survey of every file: endpoints, schemas, formulas, localStorage keys, line numbers, and known bugs.

| Target | Type | Reference doc |
|---|---|---|
| `survey/` | Company training-needs survey. Python standard library + SQLite, runs locally | [docs/survey.md](../../docs/survey.md) |
| `survey-vercel/` | Vercel + Supabase port of the survey above (https://education-survey.vercel.app) | [docs/survey-vercel.md](../../docs/survey-vercel.md) |
| `comfort-letters/` | "퇴근길 빡침 우체통", an anonymous venting messenger. Vercel + Supabase | [docs/comfort-letters.md](../../docs/comfort-letters.md) |
| `commute-break/` | A deployable copy of `퇴근길쉼표.html` (Vercel, static) | [docs/commute-break.md](../../docs/commute-break.md) |
| `wake-alarm.html`, `출근 전 점검표.html`, `콩알이키우기.html`, `퇴근길쉼표.html`, screenshots | Single-file HTML apps at the root | [docs/root-html.md](../../docs/root-html.md) |
| `voice-notes/` | Recording → faster-whisper → `claude -p` summary and meeting minutes. Python, own `.venv` | [voice-notes/README.md](../../voice-notes/README.md) |

## 비밀값
